# 板块 L：低电感高速电机调试方法

> 本板块记录"低电感、低电阻、高速"永磁同步电机（PMSM）的调试经验。
> 这类电机常被用于航模、高速风机、小型电机等场景，电感/电阻比普通电机小一个量级，
> 电气时间常数很短。
>
> **只收录已实测验证或严格物理推导确认的调试方法与判断思路。**
> 全部以"思路/物理规律/判断方法"形式书写，不绑定任何芯片、文件路径或固件数值。
> 换到不同芯片或驱动板时，按相同思路用当前项目的实际数值重新计算即可。
>
> 参考来源：从"电感电阻适中电机"适配"电感电阻极小电机"的完整调试过程。

## 1. 这类电机的关键特征（物理，换芯片不变）

判断目标电机是否属于"低电感高速"类型，先看以下物理特征是否同时成立：

- **电感 L 很小、电阻 Rs 也很小** → 电气时间常数 τ = L/R 很短（可能只有几十微秒）。
- **额定转速 / 目标转速高** → 反电动势（电机常数）可能较弱，强拖到顶时反电动势幅值小。
- **电流纹波对电压扰动极敏感**：同样一个电压扰动造成的电流变化 ΔI ≈ V·Ts/L，
  与 L 成反比。L 小一个量级，同样的扰动造成的电流跳变就大一个量级。

**为什么这类电机难调**：控制环路的采样周期、离散化、死区等"本可忽略"的误差，在
低电感电机上会放大一个量级，从"可忽略"变成"与信号同量级"，必须逐项处理。

## 2. 最容易踩的坑（按排查优先级排序）

### 坑 1：观测器电流估计器离散化病态（最常见、最先查）

**现象**：位置观测器（如滑膜观测器）输出角度冻结/不旋转，或转速估计失效。

**物理根源**：电流估计器的前向欧拉离散化存在稳定条件——**采样周期必须小于电气时间
常数（Ts < τ = L/R）**。低电感电机 τ 很小，可能小于采样周期，此时离散化系数变负，
模型变成符号翻转的振荡器，观测器无法收敛，反电动势估计退化为恒定直流，锁相环被锁
死在伪平衡点。

**判断方法**：先算 `Rs·Ts/L`。若其值接近或大于 1，就说明离散化处于或逼近病态。

**处理思路**：改用隐式（后向）欧拉离散化。公式结构不变，只换系数求法
（`1/(1+Rs·Ts/L)` 形式），观测器主体算法一行不用改。这是"改系数即可修复"的典型。

**排查提示**：观测器角度**恒定冻结为某个固定负值** ≠ 观测器本身故障。先查它的输入
（反电动势估计 eα/eβ）是否退化为 0 或恒定常数。若输入已退化为恒定负常数，锁相环会
停在某个伪平衡点，这通常是离散化病态的间接表现。

### 坑 2：死区 / 管压降误差与信号同量级

**现象**：电流闭环出现低频振荡、电流与转速同频波动、换向噪声明显；删除死区补偿反而
恢复，或加了补偿后电流剧烈跳动。

**物理根源**：死区时间使逆变器实际输出电压比指令低一块，损失约等于
`死区时间比例 × 母线电压`。低电感电机上，同样一个电压误差造成的电流跳变被放大
（L 小 → ΔI 大），死区误差从"可忽略"变成"与指令电压同量级"，必须补偿。

**处理思路**（死区补偿，关键判断点）：
- **占空比补偿 + 电压模型补偿必须同步做、同方向、同数值**。只在占空比里补而不同步
  修正电压模型，观测器的电压输入就会和实际输出对不上。
- **电流方向判定的方法决定补偿成败**。低电感电机电流纹波大、采样噪声高，直接拿瞬时
  相电流符号判断会过零乱跳，每次误判都是一次电流冲击。改用**电压矢量角推导的三相电压
  方向**来近似电流方向（功角足够小时电流方向≈电压方向）。
  - ? 推导时相位必须取对：用电压的 COS 分量推方向，用错相位（差 90°）方向会反。
  - ? 过零附近要设一个不补偿的窗口，避免方向判定抖动。
- **补偿是否"该做"取决于误差占比，不取决于电机是否新**。对电感大的电机，死区损失占比
  小，补偿引入的扰动可能被高增益电流环放大，反而是负收益（这就是"老电机本来能跑，
  别乱加补偿"的原因）。

### 坑 3：观测器锁到"强制激励"而非"真实转子"

**现象**：强拖阶段位置观测器的角度差（真实角度与观测角度之差）不在设计平衡点停留，
而是呈现"长时低值微波动 / 无规则震荡后再收敛"等异常形态，导致切入闭环后过流。

**物理根源**：低电感电机反电动势在低速强拖时很弱，与滑膜切换噪声、电流纹波、死区残余
**同量级**。锁相环会锁到强制电压激励在电流上留下的特征上（自锁），而不是真实转子的
反电动势。

**判断方法**：看观测器角度差的收敛形态——真正"锁到转子"应停在设计平衡点并保持平稳；
若停在偏离平衡点的低值、且底下有与滑差频率对应的缓慢微波，说明锁到了激励特征而非转子。

**处理思路**：**先抬信号，再谈判据**（通用原则的具体体现）。
- 先想办法抬高强拖时的反电动势信噪比（提高强拖顶速、加大强拖电流），让观测器信号从
  噪声里"站出来"。
- ? 抬顶速/抬电流必须在电机永磁体线性反电动势区、不超机械允许转速的前提下。
- 信噪比不足时，怎么改判据都会被骗，所以先解决信噪比。

### 坑 4：PLL 积分器无限幅导致转速虚高

**现象**：观测器输出转速虚高到物理不可能的值（远超强拖顶速），然后溢出跳变回负数。

**物理根源**：锁相环速度积分是裸积分器、无限幅。输入误差信号不干净（均值非零）时，
积分量线性累积 → 转速虚高 → 数值溢出跳变。

**判断方法**：转速是**观测估计值不是测量值**。观测器未锁定时，转速会虚报，任何基于
转速的判据（比如"转速达到阈值才算锁定"）都可能被这种虚报骗过。

**处理思路**：
- 给 PLL 速度积分加**合理限幅**，防止虚高溢出。
- 更重要：不要用"转速达到某值"作为观测器已锁定的唯一判据，要看角度差的收敛形态。

### 坑 5：强拖失步且无法自恢复（启动流程认知）

**物理认知**：开环强拖阶段，转子一旦失步就无法自行恢复。此时观测器会**忠实跟踪失步的
真实转子**（观测角度平滑，但转速与强拖频率不同），导致"观测角度差"永不收敛到设计值。

**判断方法**：
- 强拖阶段转速反映的是**真实转子速度**（失步时忽快忽慢），不是强拖指令速度。
- "转得慢 / 磕磕绊绊转几圈"在低转速强拖下是**正常观感**，不是故障。
- 观测器锁定判据的"预期顶速"必须与强拖顶速匹配，顶速算错（如漏一位）会导致反电动势
  估计弱一个量级、观测器失明。

### 坑 6：预定位电流未爬满就进入强拖

**现象**：启动时转子未被拉到定位轴，强拖初始功角随机，后续切闭环困难。

**物理根源**：启动流程中"预定位"阶段用电流斜坡把转子拉到固定位置。如果**预定位时间
不够让定位电流爬满**（定位电流目标 ÷ 爬升速率 > 分配的时间），转子还没被拉到定位轴就
提前进入强拖。

**判断方法**：算一下 `目标定位电流 ÷ 每 tick 电流增量 × tick 周期`，与状态机分配的
预定位时间对比。时间不足就是坑。

**处理思路**：把预定位时间调大到足以让定位电流爬满。这是启动流程类问题中第一个要查的。

## 3. 这类电机调试的总结（方法层面）

1. **先做"数学体检"再上电**：上电前先手算离散化稳定性、死区损失占比、反电动势量级、
   采样/串口带宽预算。低电感电机这些误差放大一个量级，不量化必盲试。
2. **按固定层次排查**：离散化 → 死区/管压降 → 观测器锁定 → PLL → 启动流程 → 切入
   判据。每层都有对应的"现象 → 物理根源 → 判断方法 → 处理思路"，逐层排除。
3. **观测器三件套（观测角度 / 观测转速 / 反电动势估计）异常时**，先确认它们退化成什么
   形态（冻结 / 恒定 / 振荡 / 虚高），用形态反推是哪一层的物理根源。
4. **启动流程（预定位→强拖→切入）改动时**，同时盯"电流、速度、角度差"三个变量，
   三个波形互相印证。
5. **换芯片 / 换板子后**：所有数值都要用新工程的采样周期、母线电压、电感电阻重新算，
   但上面的**现象-根源-方法对应关系不变**。
