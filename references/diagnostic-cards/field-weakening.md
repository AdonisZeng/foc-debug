# 排查卡：弱磁（转速被母线电压封顶）

> 弱磁解决的不是"转矩不够"，而是"电压不够"。这一层的问题会让"该到的转速到不了"
> 被误判成电机选型/负载/速度环整定问题，白折腾很久。排查入口是**电压方程**，不是
> 环路增益；先把"电压封顶"与"电流封顶"分开，再谈弱磁。

---

## 坑1：转速被母线电压封顶（电压饱和），被误判成"带不动"

**适用标签**：`母线电压偏低` `高Ke` `风机/泵类负载` `宽压输入(115V/230V)`

**现象**：负载加到某个功率后，转速被顶在某个值不再上升；继续加负载转速掉、效率也掉；
怎么调速度环增益、怎么加电流都无效。

本机实测（AC115V，目标 1550rpm）：输出 47.58W 时转速只有 **1394rpm**，
`svp.percent=60399`（顶满 `PERCENT_MAX=60400`）、`iq_ref=1881`（未顶 `MAX_IQ=2096`）。

**物理根源**：电压方程 `|U| = sqrt(uq² + ud²)`，其中反电势项 `∝ ω·ψf`。母线固定 →
SVPWM 线性区能给的电压上限固定 → 该电压能支撑的转速上限固定。负载加重使 iq 增大，
`Rs·iq`、`ωLq·iq` 两项吃掉电压裕量，转速只能回落到反电势项变小为止——**不是转矩不够，
是没电压**。

窄母线 + 高 Ke 电机时这个上限可能就落在额定点附近：115V 整流 ≈163V DC，SVPWM 线性区
相电压峰值 ≈0.577·Vdc ≈94V，而 115V 绕组额定点的反电势峰值 ≈115·√2/√3 ≈94V——
**设计裕量接近零**，50W 级负载就足以把转速从额定点压下来。

**判断方法**：

1. **同屏观测 `percent / iq_ref / speed`（首选，一眼定性）**：
   - `percent` 顶到 `PERCENT_MAX` → 电压天花板（本坑）；
   - `iq_ref` 顶到 `MAX_IQ` 而 `percent` 未饱和 → 转矩/电流限幅，转 `speed-loop.md` 坑2；
   - 两者都没顶（`iq_ref` 停在一个低于 `MAX_IQ` 的值上）→ 查功率/降额类软限幅
     提前压低 iq 上限，转 `speed-loop.md` 坑5。
2. **调压器改母线电压**：转速随母线电压成比例变化 → 坐实电压封顶（属硬件性上限）。
3. **负载-效率表看包络**：输出功率爬到某点后转速开始掉、效率在重载段持续下滑，即进入
   渐进饱和；与"无补偿基线"的交叉点就是"电压不够"的计量起点。
4. **由 `percent` 反算电压校验刻度**：`percent=60400`(满调制) ↔ 相电压峰值 `Vbus/√3`，
   可反推 Ke 与"id=0 下的满电压转速"，与实测转速对照是否吻合。

**处理思路**：

- **软件侧**：弱磁（注入负 id，见坑2~坑6）换转速裕量，不动控制判据。
- **硬件侧才是根治**：提高母线电压 / 换低 Ke 电机 / 改绕组接法。**先核对绕组接法与输入
  电压是否匹配**——双电压电机（标称 115V/230V）若误按 230V 接法跑 115V 供电，等于凭空
  多欠一倍电压。
- 顺带核对"满调制对应转速"类转速域常量是否按本电机重标（旧平台常量会让整条转速域错位，
  见 `motor-profiles/hv-fan-motor.md` 坑4 连带发现）。

**边界**：本坑（电压封顶）与 `speed-loop.md` 坑2（电流封顶）**现象相同、处理相反**。
先分清是哪一个再动手——电流封顶时加负 id 只会更糟（分流 iq、白付铜损）。

## 坑2：想用"改角度基准/补偿角"提转速——入口错了，应改为注入负 id

**适用标签**：`dq电流环架构` `霍尔/无感通用`

**现象**：有人建议"把 90° 基准角改小（或加大电压超前角）让电流矢量偏离 q 轴、产生
−id"，甚至直接改角度宏数值或角度表的全局偏移。

**物理根源**：在 dq 电流环架构里**电压矢量角是结果、不是操作量**：
`dq_theta = arctan(−ud, uq)` 由 d 轴/q 轴电流环各自输出的 ud/uq 合成。直接改角度基准
= 开环注入：电流环并不知道角度被偏了，仍按原 ud/uq 调节，被偏掉的电压矢量在 dq 域表现为
交叉耦合扰动，d 轴电流环会把电流拉回 id=0 对抗它 —— 效果打折甚至低频振荡；且实际 id/iq
失控，电流限幅形同虚设，偏深了直接撞软/硬过流。
（顺带：若按电压矢量角理解，"基准角减小"是让矢量往 d 轴**滞后**转，而弱磁要的是超前，
方向也是反的。）

**判断方法**：检查负 id 的注入点。正确入口只有一个——**d 轴电流给定 `id_ref`**。
给 `id_ref` 负值 → d 轴电流环真实跟踪出负 id → `ud = Rs·id − ω·Lq·iq` 变负 →
`arctan(−ud, uq)` 自动加大超前角。"电压超前角"是负 id 的自然产物、闭环自洽，无需人工
标定，也就不存在"扫哪个角度效率最高"这个问题。

**处理思路**：改 `id_ref` 一行参数即可；不要动角度基准宏与角度表。

**边界**：无感观测器电压模型的角度/参数偏置属于另一类问题（属角度或参数标定），不要与
本坑混用。

## 坑3：固定负 id（开环弱磁）在轻载白付效率税 → 改闭环"按需给药"

**适用标签**：`宽压输入` `多档转速` `轻载占比高的应用(风机)`

**现象（本机实测，AC115V 恒速负载表，固定 id=−400 vs 无 id 基线）**：

| 输出功率 | 无 id 效率 | 固定 −400 效率 | Δ |
|---|---|---|---|
| ~5W   | 52.0%  | 44.78% | **−7.2pp** |
| ~20W  | ~72.2% | 69.52% | −2.5pp |
| ~30W  | 72.4%  | 72.28% | ≈0（**交叉点**） |
| ~45W  | 69.2%  | 71.20% | **+2.0pp** |
| 输出包络 | 46.2W@1520rpm 后掉速 | **51.93W** | 包络 +12% |

**物理根源**：弱磁电流沿 d 轴不作功、但照样 I²R 发热，是"废电流"。**需要多少弱磁由
电压裕量决定，不由 iq（负载）单独决定**——还取决于转速与母线电压：同一 iq 在 230V 输入、
或低速档、或轻载时电压裕量充足，弱磁纯属白付。故固定值在任何单一标定下都无法两头兼顾
（轻载亏、重载赚），且要按每个"电压×转速×负载"组合重标。

**判断方法**：做"同转速、负载递增"的效率表，与无弱磁基线配对比较找交叉点；或直接观测
`percent` 是否饱和——只在饱和工况才需要弱磁。

**处理思路**：**闭环弱磁**——以电压饱和量为误差、`id_ref` 为输出的慢积分环（实现见
坑4~坑6）。本质是把"扫参找效率最高点"变成控制环在线自动收敛：**误差存在才加深，误差
消失即停手**，收敛点天然是"刚好够用的最小负 id"，也就是效率最优点；230V/轻载自动归零，
不白付税。参考参数（本机）：`FW_KP=1024`、`FW_KI=128`，节拍 = 速度环节拍
（本机 `SPEED_CONRTOL_FRE`=15ms）。

**边界**：负 id 加深后转子磁链被削弱，高速/高温下永磁体退磁风险上升，深度上限要单独夹住
（见坑5）；另有"弱磁降效率 → 同样输出下输入功率升高"的副作用，会牵连功率限值类逻辑
（见坑5）。

## 坑4：弱磁环给定取"等于饱和限幅值"→ 误差恒 0、弱磁永不介入

**适用标签**：`以调制度(percent)为反馈的弱磁环`

**现象**：按调制度做反馈的弱磁环，给定设成 `PERCENT_MAX`，电机明明饱和了却完全不见
弱磁介入。本机实测踩点：给定 60400 → 不动；下调到 60000 才生效。

**物理根源**：电压饱和时 `percent` 被 SVPWM 的圆限幅钉在 `PERCENT_MAX`（本机 60400），
若给定 = `PERCENT_MAX`，则 `误差 = 给定 − 反馈 = 0` 恒成立，PI 输出恒 0。**给定必须比
饱和值低一档**，才能"一饱和即产生负误差"。

**判断方法**：饱和工况下看弱磁环的误差与输出是否恒 0；把给定下调一档再试。

**处理思路**：

- 给定取比 `PERCENT_MAX` 低一档的**调节点**，留触发余量（本机 60000 vs 60400，余量
  400 码 ≈0.6% 满调制，对应约 91.6% 调制）。余量太小则介入点贴边、控制残差被削掉；
  太大会提前弱磁、白付铜损。
- **反馈下限也要钳**（本机 59000）：轻载/低速时 `percent` 深跌会产生很大的正误差
  （本机 `PIControl` 内部只钳 +7000），输出被钳在 0 期间积分器的反向驻留量正比于误差
  幅度，电压重新饱和时弱磁会带大突跳。把正误差压到 ≤1000 量级，重入更平缓。
- PI 用**反算抗饱和**（本机 `PIControl` 带 Kc 反算）：输出饱和期间积分器被钉在限幅
  边界，电压一重新饱和负 id 即时建立、不拖滞。

**边界**：反馈取 `percent` 而非"uq 限幅误差"是"够用就好"的选择——`percent` 已被圆限幅
饱和，看不出"需求超了多少"，但对"该不该弱磁、往哪边调"足够用；若要更快的弱磁响应，
可换用"uq 限幅被削掉的量"作反馈（见 `sampling-modulation.md` 坑2 的钳位自检思路）。

## 坑5：弱磁深度上限、电流预算与功率限值的耦合

**适用标签**：`双电阻/单电阻采样` `带软件过流` `带功率限值/退磁逻辑`

**现象**：弱磁加深后相电流超预算、撞软过流停机；或弱磁后效率下降使输入功率升高，
触发"功率超限退磁"把 iq 压掉、弱磁效果被自己打回。

**物理根源**：

1. 相电流幅值 `= sqrt(id² + iq²)`。弱磁注入 −id 会**挤占电流预算**：原有 iq 限幅是
   "方形"的（只管 iq、不看 id），id≠0 时它不再等于总电流上限，`sqrt(id²+iq²)` 可能悄悄
   越过软件过流阈值。
2. 弱磁是靠"废电流换电压"，必然降低效率；同样输出功率下**输入功率升高**，若系统里有按
   输入功率触发的限流/退磁逻辑，会被误触。

**判断方法**：

1. 观测相电流幅值 `sqrt(id²+iq²)` 峰值 vs 软过流阈值（本机 2621 码≈2.0A）；
2. 观测输入功率观测值是否逼近功率限值宏（本机 `POWER_PROTECT_MAX=90W`），以及限流逻辑
   触发时 iq 限值 `svp.max_iq` 是否被压。

**处理思路**：

- **弱磁深度上限单独夹住**：本机把弱磁 PI 的输出限幅设成 `[0, −500]`（上限 0 表示不产生
  正 id；≈0.38A 上限按退磁与电流预算定），并在函数出口再加一道 `[−1000, 0]` 兜底，
  防日后调宽限幅参数导致深度失控。
- 有条件时把 iq 限幅从**方形改电流圆**：`iq ≤ sqrt(I_max² − id²)`，保证 id≠0 时总电流
  不越界（本机尚未实施，仍是方形限幅，属已知待补项）。
- 核对功率限值逻辑与弱磁后新工作点的关系：定性自洽（iq 被压 → uq 需求降 → 弱磁积分自然
  停），但更重载时会与弱磁耦合，需实测定论。

**边界**：深度上限必须结合退磁风险与电机热能力定，不能只按"能拉到目标转速"取。

## 坑6：到速后主动泄放弱磁（省轻载铜损的工程处理）

**适用标签**：`多档转速` `轻载占比高` `弱磁仅重载才需要`

**现象**：闭环弱磁一旦建立，到了目标转速仍挂着负 id —— 轻载时纯耗铜损（即坑3 表中
左半段的 3~7pp 效率税）。

**物理根源**：弱磁环的被控量是"电压饱和量"，而"到没到目标转速"是另一个独立信息。
只用饱和量做反馈时，给定一满足就停在某个负 id 上，不会主动回收。

**判断方法**：到速轻载工况下观测 `id_ref` 是否仍为负、`percent` 是否已明显低于调节点。

**处理思路**（本机实现，供参考）——以"**实测转速 ≥ 目标转速**"为界做分支，不必另加滞环：

- **未到速**（`speed < target_speed`）：反馈跟踪实时 `percent`，弱磁随饱和深度自动加深，
  允许带负 id 继续升速冲进弱磁区——这是弱磁存在的目的；
- **到速后**：反馈冻结并主动往 0 泄放；若上拍反馈仍 > 调节点（误差卡在负侧、输出泄不
  下来），把反馈压到调节点以下令误差翻正，输出即平滑退回 0。负载重到电压再饱和、转速跌回
  目标以下时会自动重进跟踪分支——**以目标转速为界自然开断，免滞环**。
- 泄放/重建速率由弱磁环 Ki 决定（本机 `FW_KI=128`，速度环节拍 15ms 折算满量程
  ≈5s 量级）：慢，才不会与速度环抢方向盘，但也不宜再快。

**边界（推导，未实测，使用前需台架确认）**：在"恰好能做目标转速"的重载窄带内，
"泄放 → 掉速 → 重建"可能形成慢周期转速摆动（幅度/周期取决于 `FW_KI` 与负载斜率）。
台架宜在该负载带录长波形确认；若不可接受，可把"到速泄放"改为"按饱和量滞环回收"
（反馈带死区，只在明显有余量时才回收）。

## 关联修复与待隔离项（非独立验证结论，引用时需谨慎）

- **接入弱磁后发现 AC115V 下相电流波形异常，该次修复同时提高了电流环积分增益**
  （`CURRENT_KI` 8192→36384）。该次提交还同时改了速度环增益/节拍与给定斜坡，
  **未做单项隔离**，故不能断言"波形异常由电流环带宽不足引起"。参考意义：弱磁的 −id 是
  d 轴电流环的**真实给定**，d 轴环带宽/积分增益不足时 −id 跟不上指令、id/iq 交叉耦合
  会显为波形畸变；换低电感电机后若增益仍继承旧平台，应优先按实测 Rs/L 重算
  （见 `current-loop.md` 坑1）。
- **方形 iq 限幅未改电流圆**（见坑5），属已知待补项。
- **原 MTPA 曲线函数成为死代码**：本机原设计里 `id_ref` 来自 MTPA 解析式
  `id = a − sqrt(a² + iq²)`（常数按旧电机推算），换电机后既未重标、也不解决电压问题；
  对表贴式电机（Ld≈Lq）其理论最优本就是 id=0。接入弱磁环取代它之后该函数已无调用点，
  宜删除或明确标注，避免日后误以为 id_ref 仍走 MTPA。
