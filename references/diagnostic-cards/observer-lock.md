# 排查卡：观测器锁定（SMO / PLL）

> 观测器是无感 FOC 的核心。观测器输出的转速、角度、反电动势都是"观测结果"而不是
> 直接测量。观测器异常时，先确认它退化成什么形态（冻结 / 恒定 / 振荡 / 虚高），
> 用形态反推是哪一层的物理根源。

---

## 坑1：电流估计器离散化病态（低电感电机最常见）

**适用标签**：`L<1mH` `低电感` `电气时间常数小`

**现象**：位置观测器输出角度冻结/不旋转，或转速估计失效。

**物理根源**：电流估计器的前向欧拉离散化存在稳定条件——**采样周期必须小于电气时间
常数（Ts < τ = L/R）**。低电感电机 τ 很小，可能小于采样周期，此时离散化系数变负，
模型变成符号翻转的振荡器，观测器无法收敛，反电动势估计退化为恒定直流，锁相环被锁
死在伪平衡点。

**判断方法**：先算 `Rs·Ts/L`。若其值接近或大于 1，就说明离散化处于或逼近病态。

**处理思路**：改用隐式（后向）欧拉离散化。公式结构不变，只换系数求法
（`1/(1+Rs·Ts/L)` 形式），观测器主体算法一行不用改。这是"改系数即可修复"的典型。

**排查提示**：观测器角度**恒定冻结为某个固定负值** ≠ 观测器本身故障。先查它的输入
（反电动势估计 eα/eβ）是否退化为 0 或恒定常数。若输入已退化为恒定负常数，锁相环会
停在某个伪平衡点，这通常是离散化病态的间接表现。

## 坑2：观测器锁到"强制激励"而非"真实转子"

**适用标签**：`低反电动势` `低速强拖` `所有电机`

**现象**：强拖阶段位置观测器的角度差（真实角度与观测角度之差）不在设计平衡点停留，
而是呈现"长时低值微波动 / 无规则震荡后再收敛"等异常形态，导致切入闭环后过流。

**物理根源**：低反电动势电机在低速强拖时反电动势很弱，与滑膜切换噪声、电流纹波、死区
残余**同量级**。锁相环会锁到强制电压激励在电流上留下的特征上（自锁），而不是真实转子的
反电动势。

**判断方法**：看观测器角度差的收敛形态——真正"锁到转子"应停在设计平衡点并保持平稳；
若停在偏离平衡点的低值、且底下有与滑差频率对应的缓慢微波，说明锁到了激励特征而非转子。

**处理思路**：**先抬信号，再谈判据**（通用原则的具体体现）。
- 先想办法抬高强拖时的反电动势信噪比（提高强拖电流以抬高同步极限转速、在同步极限内
  尽量提高强拖顶速），让观测器信号从噪声里"站出来"。
- 抬顶速/抬电流必须在电机永磁体线性反电动势区、不超机械允许转速的前提下。
- 信噪比不足时，怎么改判据都会被骗，所以先解决信噪比。

## 坑3：PLL 积分器无限幅导致转速虚高

**适用标签**：`所有电机`

**现象**：观测器输出转速虚高到物理不可能的值（远超强拖顶速），然后溢出跳变回负数。

**物理根源**：锁相环速度积分是裸积分器、无限幅。输入误差信号不干净（均值非零）时，
积分量线性累积 → 转速虚高 → 数值溢出跳变。

**判断方法**：转速是**观测估计值不是测量值**。观测器未锁定时，转速会虚报，任何基于
转速的判据（比如"转速达到阈值才算锁定"）都可能被这种虚报骗过。

**处理思路**：
- 给 PLL 速度积分加**合理限幅**，防止虚高溢出。
- 更重要：不要用"转速达到某值"作为观测器已锁定的唯一判据，要看角度差的收敛形态。

## 附：start_theta_delta 波形判读方法

`start_theta_delta`（观测角度 - 强拖角度）是判断强拖段观测器是否锁定转子的最关键
信号。判读方法：

| 波形形态 | 含义 | 动作 |
|------|------|------|
| 近似恒定值（两条曲线平行，差值稳定） | 同步锁定，正常 | 可切入 |
| 满幅抖动/不断绕卷（int16 边界来回跳） | 失步滑极，转子没跟上 | 降强拖目标 or 提强拖电流 |
| 偏离平衡点的低值 + 缓慢微波 | 锁到强制激励而非转子 | 抬反电动势信噪比 |
| 快速穿过切入窗，偶尔连续 N 拍 | 噪声碰巧命中判据 | 修前置环节，别改判据 |
| 稳定停在窗内中部，慢慢靠近平衡点 | 真正收敛 | 可切入 |

**关键认知**：`start_theta_delta` 在强拖段如果是满幅抖动/绕卷，是**强拖失步**（物理
问题），不是观测器问题。观测器在忠实跟踪失步的真实转子。修观测器参数没用，要修强拖
同步（降目标转速 or 提强拖电流）。
