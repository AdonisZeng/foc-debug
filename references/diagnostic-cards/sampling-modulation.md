# 排查卡：采样与调制（死区 / 管压降 / 电流纹波）

> 采样和调制是 FOC 的基础层。这一层出问题会向上传导到电流环、观测器、速度环，
> 表现为电流振荡、观测器失锁等。低电感电机上，采样和调制误差被放大一个量级，
> 从"可忽略"变成"与信号同量级"。

---

## 坑1：死区 / 管压降误差与信号同量级

**适用标签**：`L<1mH` `低电感` `低压电机`

**现象**：电流闭环出现低频振荡、电流与转速同频波动、换向噪声明显；删除死区补偿反而
恢复，或加了补偿后电流剧烈跳动。

**物理根源**：死区时间使逆变器实际输出电压比指令低一块，损失约等于
`死区时间比例 × 母线电压`。低电感电机上，同样一个电压误差造成的电流跳变被放大
（L 小 → ΔI 大），死区误差从"可忽略"变成"与指令电压同量级"，必须补偿。

**处理思路**（死区补偿，关键判断点）：
- **占空比补偿 + 电压模型补偿必须同步做、同方向、同数值**。只在占空比里补而不同步
  修正电压模型，观测器的电压输入就会和实际输出对不上。
- **电流方向判定的方法决定补偿成败**。低电感电机电流纹波大、采样噪声高，直接拿瞬时
  相电流符号判断会过零乱跳，每次误判都是一次电流冲击。改用**电压矢量角推导的三相电压
  方向**来近似电流方向（功角足够小时电流方向≈电压方向）。
  - 推导时相位必须取对：用电压的 COS 分量推方向，用错相位（差 90°）方向会反。
  - 过零附近要设一个不补偿的窗口，避免方向判定抖动。
- **补偿是否"该做"取决于误差占比，不取决于电机是否新**。对电感大的电机，死区损失占比
  小，补偿引入的扰动可能被高增益电流环放大，反而是负收益（这就是"老电机本来能跑，
  别乱加补偿"的原因）。

## 坑2：轻载/空载工作点顶到调制上限（电压饱和），电流环失去整形能力

**适用标签**：`高Ke` `母线电压偏低` `大电感(L≫10mH)` `空载/轻载台架`

**现象**：相电流波形明显非正弦（毛刺、平顶、凹陷），与正弦差距大；电机能正常加速、
电流幅值也能跟上给定，但波形就是不好看；改霍尔角度标定、中断优先级、降低电流给定
等均无效。

**物理根源**：电压需求 `|U|=sqrt(uq²+ud²)` 随转速近似线性增大。当电机 Ke 与母线电压
不匹配时，**空载/轻载就会被电压上限钳死**——空载时负载转矩≈0，恒转矩给定下电机一路
加速直到调制比顶到上限（不是"带不动"，是"没电压"）。一旦 `|U|` 顶到 SVPWM 上限：
- 电流环只剩很小的功率角自由度，**没有电压余量去修正任何扰动**（反电势谐波、死区、
  角度纹波、采样误差全部原样进电流）；
- 高调制下部分相的低边导通窗被压缩到几 µs，采样点靠近开关沿，波形出现毛刺。

**判断方法**（实测判据，任一即可定性）：
1. 观测三通道 `调制比 / uq / 转速`：调制比接近 `PERCENT_MAX` 即饱和；
2. **钳位自检（更严格，可自证）**：由调制比反算电压矢量模长（`|U|=percent/2`）与上限
   （`us_max=PERCENT_MAX>>1`）比较；再由 `uq` 反解 `|ud|=sqrt(|U|²−uq²)`，代回钳位公式
   `uq_max=f(ud)`；若算出的 `uq_max` 与实测 `uq` 只差几个 LSB，即确认 uq 被钳死
   （本机案例：算出 29472 vs 实测 29471）；
3. 调压器改母线电压：**转速随母线电压成比例变化**即证明转速上限是电压封顶；
4. **速度闭环对照（实测验证，2026-09）**：切入速度闭环、目标转速设为远低于空载电压
   极限转速（本机 1000 vs ≈4900）：若调制比从顶满显著回落，即证明原饱和是"空载恒转矩
   把转速推到电压上限"（**工况性**，可软件解决），而非母线/电机硬性不匹配（**硬件性**，
   只能弱磁/提压/换电机）。物理解释：电压需求主项=反电动势 ∝ 转速，闭环定低速即直接
   抽走该项（本机 129.6V@4801 → ≈27V@1000）。

**处理思路**：
- **先分清是不是测试工况问题**：空载是这类电机的最坏工况（转速最高→调制最高→电流
  最小）。要降低工作点再看波形，只能降低**转矩给定**沿机械负载线下移，或用速度闭环
  定速（**已实测验证，2026-09**：恒转矩开环 percent 顶满 → 切速度闭环定 1000 rpm 后
  percent 显著回落，见判断方法4）；**不要用"钳调制比降电压"来降速**——环路照样饱和、
  波形不变，是无效实验（只会得到假阴性）。
- 恒转矩 + 自由轴（无叶轮/零摩擦）台架上，电机永远顶在电压上限，**降电流给定也降不
  下来转速**（本机 iq 降到 50 仍同现象）——空载台架测不出额定工作点的波形，必须带载
  （风机负载）或闭环定速。
- 若确认母线/电机不匹配（额定点就顶上限）：这是硬件级问题，软件只能下调额定转速指标，
  或换低 Ke 电机 / 提高母线 / 做弱磁。
- 顺带检查：高调制下用起占空比上下限（保证采样窗）、电流环增益按电机实际电感重算
  （见 `current-loop.md` 坑1）。

**边界（避免误用）**：本条只解释"轻载/空载 + 波形畸变 + 能正常运转"这一类。重载下也
畸变时，优先回坑1（死区）或查反电势谐波/采样链。

**验证状态（本机案例，2026-09）**：速度闭环定速路径已实测——切入速度环 + 目标
1000 rpm 后调制比不再顶 `PERCENT_MAX`（实例见 `motor-profiles/hv-fan-motor.md` 坑4
补充实测），电压饱和根因进一步确认；带载（叶轮到货）后**波形是否随之改善**仍待验证
——若改善则本条完全成立；若带载后仍畸变，转查反电势谐波与采样链。

## 坑3：改三相 PWM 引脚/相序后，相电流采样通道（ADC/运放映射）未同步适配

**适用标签**：`换板/改板` `原理图校对` `运放/双电阻采样` `IO重映射`

**现象**：按原理图校对并修改三相 PWM 输出引脚（如 U/V 相对调）后，电机一跑即触发
硬件过流锁死；观测 iq 本应为正（电动状态）却读出负值。霍尔角度、电流环增益、保护
阈值均未动过，单看这些参数完全对不上号。

**物理根源**：**"PWM 引脚→相"与"采样通道→电流变量"是强耦合的两条映射链**。
运放/ADC 输入在硬件上固定接某一相的采样电阻，代码里"ADC 通道 → iu/iv"的映射必须与
"PWM 引脚 → U/V/W"指向同一套物理相序。只改 PWM 引脚、不改采样通道映射时，Clarke
变换吃进去的 iu/iv 实际是错相电流：电流反馈矢量与输出电压矢量错位，电流环等效正反馈
（给定正 iq 实际被推向反向电流），真实电流瞬间冲到硬件过流阈值；采样相序错位同时使
iq 反馈符号整体反掉——"应为正、读出负"。这是**接线级错位**，不是参数整定问题，
调环路增益/保护阈值都救不回来。

**判断方法**：
1. **两条映射链并排核对**：把"PWM 引脚（UH/UL/VH/VL/WH/WL）→ 相"与
   "运放输入/ADC 通道 → iu/iv 变量"逐相写在纸上对照；两条链中任何一条有改动，
   都必须检查另一条是否需要联动。
2. **iq 符号自检**：电动状态下稳态 iq 应与转矩同号（正转给定下为正）。若 iq 稳定
   为负而电机仍在加速/过流，优先怀疑电流反馈的相序/符号错，而不是速度环参数或负载。
3. **静态验证（不使能 PWM）**：手转转子或用万用表逐相确认运放输出脚与 ADC 原始码的
   对应关系，核对"通道 → 相"映射与原理图一致。

**处理思路**：
- **AI 助手行为要求（写死）**：做"代码 vs 原理图"IO 校对、涉及三相 PWM 输出引脚
  变更时，必须同步打开相电流采样通道配置（ADC 多通道/运放通道 → iu/iv 映射）核对
  是否需要跟着改；**若自己不确定是否需要联动修改，必须主动向用户发出提醒**，
  不得默默假定"只改 PWM 引脚、采样不受影响"。
- 修正采样通道映射后，先用低电压/小电流空载验证 iq 符号与相电流波形正常，
  再恢复正式参数试跑。
- 本机案例（RY7212 DIMAN / PM5408，2026-09）：U/V 相 PWM 引脚按原理图 U9 修正后，
  `foc_init.c` 相电流多通道配置（`ADC_MultiChannel1Config/2Config` → OP0/OP1）
  未跟着改，导致一跑即硬件过流、iq 应为正读出为负；同步修正采样通道映射后恢复。

**边界（避免误用）**：若 PWM 引脚与采样映射**都没改过**却出现 iq 符号反，先查方向宏
（如 `ELEC_INC_IS_CW`）与霍尔角度表方向（见 `hall-sensor.md` 坑4），不要套用本条。
