# 排查卡：速度环（转速控制 / 转速限制）

> 速度环在切入闭环（pi_control=1）后接管 iq_ref 的调节。速度环问题通常表现为
> 转速上不去、转速波动、iq_ref 异常。排查时先确认速度环 PI 公式实现是否正确，
> 再看电流限幅，最后看增益整定。

---

## 坑1：增量式 PI 公式实现错误

**适用标签**：`所有电机` `代码审查`

**现象**：速度环怎么调都不对，调参效果与预期相反（调 Kp 像在调积分、调 Ki 像在调比例）。

**物理根源**：代码名义上是"增量式 PI"，实际公式结构写反了。标准增量式 PI 应为：
```
ΔU = Kp * (e(k) - e(k-1)) + Ki * e(k)
```
即比例项乘误差增量、积分项乘误差。但错误实现写成：
```
U = Kp * error + Ki * (error - error_last)
```
即比例项乘误差、积分项乘误差差分（实际是微分作用）。这导致：
- 代码里的 Kp 实际起积分作用，Ki 实际起比例（微分）作用；
- 调参语义与标准 PI 相反，容易误调。实测中该错误在特定工况下可能表现不明显
  （与正确实现效果接近），但语义混乱会造成误调。

**判断方法**：检查 PIControl_inc_float（或等效函数）的公式结构。如果比例项乘的是 error
本身（而非 error 的差分），积分项乘的是 error 的差分（而非 error 本身），就是此坑。

**处理思路**：改为标准增量式公式 `U = Kp*(Error-error_last) + Ki*error_limit`。
修改后，原 KP/KI 数值需要**对调**以保持原有整定效果（因为旧 Kp 实为积分作用、旧 Ki
实为比例作用）。改完后 KP 管响应快慢、KI 管消除静差，调参语义清晰。

**注意**：修改前先确认该函数的其他调用者（如加热 PID 如果用同名函数），避免牵连。
整数版和浮点版如果分开实现，只改浮点版。

## 坑2：MAX_IQ 限制最高转速

**适用标签**：`所有电机` `高速电机`

**现象**：转速卡在某个值上不去，怎么调速度环增益都没用。

**物理根源**：速度环输出 iq_ref 被 MAX_IQ 钳位。当目标转速需要的电流超过 MAX_IQ 时，
iq_ref 顶在 MAX_IQ 不再增长，电磁转矩到顶，转速被限制。

**判断方法**：
1. 打印 `cuv.iq_ref` 和 `svp.percent`：
   - 如果 `iq_ref` 顶在 MAX_IQ、`svp.percent` 远未饱和 → MAX_IQ 限制了转速；
   - 如果 `svp.percent` 已饱和（顶在 PERCENT_MAX）→ 电压天花板，需要弱磁或提高母线电压。
2. 调大 MAX_IQ 试一次，如果转速能继续往上爬 → 确认是 MAX_IQ 限制。

**处理思路**：调大 MAX_IQ。注意：
- MAX_IQ 上调后要留意硬件电流能力和软件过流保护阈值（MAX_I_PHASE），
  MAX_IQ 不应超过 MAX_I_PHASE 对应的电流值；
- 如果调大 MAX_IQ 后转速仍上不去且 svp.percent 饱和，才是电压天花板，
  需要弱磁（id_ref 给负值）或提高母线电压。

> **实测案例**：吸尘器电机（72000 RPM 级），MAX_IQ=1500 时转速卡在 ~10000 RPM；
> 调大 MAX_IQ 后转速继续上升。详见 `references/motor-profiles/vacuum-motor.md`。

## 坑3：切入后速度环接管前的"弱驱动空窗"

**适用标签**：`所有电机` `带载`

**现象**：切入闭环后电机先减速（"慢下去"），然后速度环接管后又恢复（"快上来"），
表现为"一快一慢"。

**物理根源**：切入 RUN 后到 `start_theta_delta` 伺服到 ANGLE90 之前，`pi_control=0`，
速度环不接管，`iq_ref` 停在切入瞬间的值。而 `wait_power_angle` 在强拖末段已把 iq_ref
减到低位（可能只有 100 多）。电机带着负载靠惯性和微弱电流滑行 → 掉速 → 速度环突然
使能、误差巨大、输出打满猛拉 → 加速 → 可能超调 → 又减速……形成波动。

**判断方法**：打印 `cuv.iq_ref` 和 `foc.speed`，看切入后是否有一段 iq_ref 低位停留
+ 转速下降，然后 iq_ref 突然增大 + 转速回升。

**处理思路**：
- 根本方案：做好前置环节（预定位、强拖同步），让角度差天然落在窗内、判据很快命中、
  iq_ref 还在高位时就切入，弱驱动空窗自然消失；
- 辅助方案：切入 RUN 时保住 iq_ref（冻结 wait_power_angle 的退量，或切入后先把 iq_ref
  设为预设值），等 pi_control=1 后再交给速度环。

## 坑4：增量式 PI 中 KI 太大导致欠阻尼振荡

**适用标签**：`所有电机` `增量式PI` `速度反馈带低通` `无感系统`

**现象**：稳态运行时给定目标转速阶跃（如3000→6000 RPM），转速先冲到目标以上
（如 6954 RPM，超调约 16%），再回落欠调（如 5613 RPM，约 -6%），来回振荡 1~2 个
周期后才稳定在目标附近（仍有 ±1% 上下波动）。`cuv.iq` 跟随 `cuv.iq_ref` 良好，
**`iq_ref` 峰值远低于 `MAX_IQ`**（典型现象：实测 iq_ref 仅 ~1284 而 `MAX_IQ=6554`）。

**物理根源**：

增量式 PI 的标准公式是 `ΔU = KP*(e(k)-e(k-1)) + KI*e(k)`：

- `KP` 作用在 **误差变化量 Δe = e(k) - e(k-1)** 上 → 等价于"对速度变化率的反馈"，
  **提供阻尼**（微分性质）。**这是很多人最容易搞反的直觉点：加大 KP 反而能抑制振荡。**
- `KI` 作用在 **当前误差 e(k)** 上 → 真正的积分项，**消除静差但带来 90° 相位滞后**。

KI 太大时，叠加速度反馈的低通滞后（典型如 `speed_lpf(..., 6554)` 时间常数约 4ms）
+ SMO/PLL 观测器估计延迟，**闭环相位裕度被吃光**，出现低频极限环式欠阻尼振荡：

1. **积分快速累积**：接近目标但尚未达到时，KI 项按误差线性累积（典型 `KI*5/8192≈0.18/5ms`
   量级），几个周期就到 ±5 限幅 → 触发方向反转；
2. **准 bang-bang 限幅放大**：速度环输出限幅 ±5 较小时，方向切换变成"满步长踩步"，
   `iq_ref` 呈锯齿形爬升/回落；
3. **反馈滞后放大冲过目标**：速度估计滞后使速度环"该减速时反馈未到位"→ 实际转速冲过
   目标 → 反馈追上来 → 再回调 → 形成衰减振荡；
4. **相位裕度被吃光**：积分项 90° 滞后叠加观测器/低通滞后，总相位裕度不足 → 低频极限环。

**判断方法**：

1. 用 VOFA+ 或类似工具同屏抓 `iq_ref` 和 `speed` 波形。**先看 `iq_ref` 峰值是否顶到 `MAX_IQ`**：
   - 是 → 排除此坑，去查 `speed-loop.md` 坑2（MAX_IQ 限幅类问题）；
   - 否（`iq_ref` 远低于 `MAX_IQ`）→ 进入下一步。
2. 观察振荡周期：
   - 慢振（周期在秒级） → 主要降 KI；
   - 快振（周期百毫秒级以内） → 主要降 KP。
3. 观察超调量：超调 > 10% 通常意味着 KP 偏小（阻尼不足）或反馈滞后偏大。

**处理思路**：**"PI 的 PD 化"——加大 KP、减小 KI**：

- KI 减到振荡消失的临界值附近（留一点余量给消除静差）；
- KP 同步加大以保持响应速度（KP 项提供阻尼，加大反而能抑制振荡）；
- 实测验证示例：原 `KP=2000 / KI=300` 振荡明显，阶跃后超调+衰减振荡；改为
  `KP=4000 / KI=50` 振荡消失。详见 `references/motor-profiles/vacuum-motor.md` 坑5。

**注意**：

- 调 KP/KI 前先确认 PI 公式实现是标准增量式（`U = KP*Δe + KI*e`），若公式写反了
  （见本卡坑1）调参会语义混乱；
- 每次只改一个参数，抓波形对比超调量和收敛时间；
- 不要同时大幅改动 `speed_lpf` 系数与 PI 参数，会难以判断根因。
- **"准 bang-bang" 行为本身可作为辅助诊断信号**：若 `iq_ref` 波形在大误差时呈固定
  步长 ±5 锯齿爬升（即使误差很小），就说明闭环积分时间常数 + 反馈滞后使系统在工作
  极限附近，此时降低 KI 让线性区扩大是最直接手段。

> **实测案例**：NIDEC 36V 一对极电机（参数同 `vacuum-motor.md`），原
> `KP=2000 / KI=300` 阶跃后超调+振荡；改为 `KP=4000 / KI=50` 振荡消失，
> 详见 `references/motor-profiles/vacuum-motor.md` 坑5。

## 坑5：iq_ref 停在中途不涨——被"功率/降额类软限幅"压低的 iq 上限

**适用标签**：`带载` `有功率/降额/温度保护` `功率观测量未标定` `风机/泵类负载`

**现象**：带载加到某个功率后转速上不去（或掉速后拉不回）；`iq_ref` 稳定在某个值
（典型是 MAX_IQ 的 50%~60%）小幅波动、不再增长；`percent` 在满调制附近大幅摆动
（峰值甚至短暂超过线性区上限），但远未顶到 `PERCENT_MAX`；调速度环增益、调 MAX_IQ
都无效（MAX_IQ 本来就没顶到）。

**物理根源**：速度环输出的 iq 给定通道上除了 `MAX_IQ` 还有一层**软上限**——功率保护、
母线降额、温度降额等按某个观测量每拍削减该上限，速度环输出再被这个软上限钳位。
当观测量标定偏大、或本身纹波大时，软上限会在远低于设计功率处就被压低 → 转矩被限 →
转速上不去。软上限的削减/恢复步长若不对称（快降慢升），还会叠出 iq_ref 的小幅锯齿
和 percent 的周期性起伏——这部分抖动是限幅器的振荡，不是速度环整定问题。

**判断方法**：

1. **同屏打印 `iq_ref` + 软上限变量本身 + `MAX_IQ`**（关键：不是只看 MAX_IQ）。
   若 `iq_ref ≈ 软上限 < MAX_IQ`，即命中本坑。
   与相邻坑的区别：坑2 是 iq_ref 顶 `MAX_IQ`；`field-weakening.md` 坑1 是 iq_ref
   没被钳、`percent` 顶 `PERCENT_MAX`；本坑是 iq_ref 顶在一个**更低的内部上限**上。
2. **用外部功率计量对软件功率读数**（同一工况、同一时刻）：
   - 软件读数 ≫ 实测（实测案例达 ≈1.7 倍）→ 观测量标定偏大，阈值实际在远低于
     名义功率处就触发；
   - 常见偏差来源：用**指令电压**而不是实测相电压算功率（未扣死区/管压降，
     过调制时偏高）；功率低通时间常数不足（残余 2 倍电频脉动，判据按拍采样会随机
     命中峰值）；电流码/A 未用电流钳校核；母线电压标定误差。
3. **闭环反证**：临时把该保护阈值抬高（或临时屏蔽该段），若转速与 iq_ref 同时恢复、
   percent 摆动消失 → 确认是该软限幅，而不是电压/电流天花板。

**处理思路**：

- **先标定观测量，再定阈值**：外部功率计分段（如 10/20/30W）对账得到软件读数与实测
  的比值，按比值反推阈值；能测相电压时优先用实测电压替代指令电压。
- 阈值按"实测功率"整定，不要直接拿铭牌功率×1.2 去卡未标定的软件读数（会得到
  远低于设计值的实际动作点）。
- 观测量纹波大时先把低通时间常数加大到能滤掉 2 倍电频，或给判据加滞回/多点平均，
  消除阈值附近的快降慢升锯齿。
- 若标定对账后确认软件读数准确、确实超功率，**不要放宽阈值**——转查效率、电压饱和
  （`field-weakening.md` 坑1）与负载匹配。

> **实测案例**：25W 高压风机（母线 ≈310V、目标 1600rpm、2 对极、60° 霍尔）。
> 负载加到 19W 时转速上不去；`percent` 在 22735~35023 摆动（满线性调制=32768，
> 峰值已过调制）、`iq_ref` 仅 2100~2200（`MAX_IQ=3670`）。根因是功率保护阈值
> 30W：外部实测 33W 时软件功率读数 57W（≈1.7 倍），30W 阈值按比例折算约在实测
> 17W 处就触发，软上限每 5ms 减 20 码、恢复加 10 码形成锯齿。阈值改为 60W 后
> 转速恢复、percent 摆动消失。详见 `references/motor-profiles/diman-25w-fan-motor.md`。
