# 电机档案：36V 风机电机（五对极，大惯量扇叶）

## 1. 基本信息

- **用途**：36V 风扇驱动（RY7212 平台）
- **负载特征**：大直径扇叶，**转动惯量大**，负载转矩 T∝ω^2
- **额定参数**：36V 母线，PWM 12500Hz（周期 80us），SMO+PLL 无感 FOC

## 3. 踩过的坑及解决方案

### 坑1：固定矢量盲定位启动随机失败

- **现象**：`IPD_EN=0`（固定矢量盲定位，park_theta 固定 -ANGLE90）时，风扇启动
  随机失败，失败率明显高于低惯量电机。
- **根因**：固定矢量盲定位的**角度盲区**问题 + 大惯量：
  - 盲定位只给一个固定方向的磁场，若转子初始位置恰在磁场盲区（与定位矢量接近
    垂直/磁拉力小），磁拉力不足以克服大惯量把转子可靠拽到定位角；
  - 大惯量扇叶振荡衰减慢，需要很长预定位时间才能停稳，时间不足就带着初角偏差
    进强拖，导致启动失败。
- **解决方案**：先做"两段式定位"优化（见坑2），仅部分缓解，未根治。

### 坑2：两段式定位优化后成功率大增，但仍有失败且预定位时间过长

- **现象**：把单段 `iq_ref += 2` 爬坡改为两段式——
  第一段弱磁寻位（`iq_ref` 缓爬至 `ORIENT_IQ_SOFT=ORIENT_IQ×50%` 并保持），
  第二段强磁锁死（`iq_ref += 30` 快速抬升到 `ORIENT_IQ` 并保持）——
  启动成功率大幅提升，但**预定位时间被拉到 1.6s 仍偶有失败**，对风扇应用过长。
- **根因**：两段式只是"用更长的时间、更平滑的电流"缓解了振荡衰减和过冲，
  **没有消除固定矢量盲定位的角度盲区**。盲区里转子初始位置不利时，第一段弱磁
  根本拉不到位，第二段强磁也只是在错误角度上锁死——失败率无法归零。
- **解决方案**：**改用 IPD（电感脉冲定位）**——先注入脉冲测出转子所在 60° 扇区
  （`ipd.angle`），再让预定位矢量对准该扇区（`park_theta = ipd.angle ± ANGLE60`，
  电流矢量领先转子 30° 建立正功角），从根本上消除角度盲区。
- **关键认知**：**大惯量负载下，固定矢量盲定位无论怎么加长定位时间、做两段式
  优化，都只是降低失败率，无法消除失败率。要根治必须先用 IPD 测出转子位置再
  定位**。这是"先量化、再怀疑"原则的典型应用——先解决"预定位矢量方向对不对"
  这个前置问题，而不是靠堆时间打补丁。

## 5. 实测波形特征

- **两段式优化后**：启动成功率大幅提升，但预定位阶段整体耗时约 1.6s，对风扇
  这类要求快速启动的应用偏长。
- **仍失败的启动**：失败模式与盲定位角度盲区一致——第一段弱磁寻位后转子未真正
  到达定位角，第二段强磁在错误角度锁死，进强拖后 `start_theta_delta` 初始偏差大，
  切闭环失败。

## 6. 对照结论

- 与吸尘器电机（`vacuum-motor.md`，一对极）对照：吸尘器电机预定位时间翻倍
  （1000→2000）即可根治启动失败，因为其惯量小、盲区影响小；**本机 5 对极大惯量
  扇叶，盲定位时间拉到 20000（1.6s）仍无法根治**。同样的"预定位不足"现象，
  根因层次不同——前者是"时间不够衰减"，后者是"方向没对准（盲区）+ 惯量太大
  拽不动"。这验证了"按物理根源聚合、电机特性作标签"的组织方式：盲目堆预定位
  时间对盲区型失败无效。
- 可复用经验：**遇到大惯量负载（风扇/泵）启动失败，不要盲目加预定位时间，
  先怀疑固定矢量盲定位的角度盲区，优先切 IPD 测位置再定位。**
