# 电机档案：航模电机（低电感，空载）

## 1. 基本信息

- **用途**：航模动力
- **负载特征**：空载（螺旋桨极轻载或无载）
- **额定参数**：高速（万转级以上）
- **调试时间**：早于吸尘器电机

## 2. 电机参数（实测）

| 参数 | 值 | 单位 | 备注 |
|------|------|------|------|
| 极对数 POLES_PAIR | | | |
| 相电阻 RS | 十几 | mΩ | 极小 |
| 相电感 L | 十几 | uH | 极小 |
| d 轴电感 LD | | uH | |
| q 轴电感 LQ | | uH | |

> 注：具体数值待补充。关键特征是电感和电阻都很小，电气时间常数 τ=L/R 很短。

## 3. 踩过的坑及解决方案

### 坑1：观测器电流估计器离散化病态

- **现象**：位置观测器输出角度冻结/不旋转，转速估计失效。
- **根因**：前向欧拉离散化稳定条件 Ts < τ=L/R 不满足。低电感电机 τ 很小，可能小于
  采样周期，离散化系数变负，模型变成振荡器。
- **解决方案**：改用隐式（后向）欧拉离散化，系数改为 `1/(1+Rs·Ts/L)` 形式，
  算法主体不变。

### 坑2：死区/管压降误差与信号同量级

- **现象**：电流闭环低频振荡，删死区补偿反而恢复。
- **根因**：L 小 → 电压误差造成的电流跳变被放大，死区误差从"可忽略"变成"与指令同量级"。
- **解决方案**：占空比补偿 + 电压模型补偿同步做；电流方向用电压矢量角推导而非瞬时
  电流符号；过零附近设不补偿窗口。

### 坑3：观测器锁到强制激励而非真实转子

- **现象**：强拖阶段角度差不在平衡点停留，呈现异常形态，切入闭环后过流。
- **根因**：低速强拖时反电动势与滑膜切换噪声同量级，PLL 锁到强制激励特征上。
- **解决方案**：先抬反电动势信噪比（提高强拖电流/顶速），再谈判据。

### 坑4：PLL 积分器无限幅导致转速虚高

- **现象**：观测转速虚高到物理不可能值，然后溢出跳变回负数。
- **根因**：PLL 速度积分是裸积分器，输入误差不干净时积分量线性累积。
- **解决方案**：给 PLL 速度积分加合理限幅；不用"转速达到某值"作为锁定唯一判据。

### 坑5：强拖失步

- **现象**：强拖阶段角度差不收敛。
- **根因**：开环强拖失步后无法自恢复，观测器忠实跟踪失步转子。
- **解决方案**：确认强拖顶速与预期匹配（顶速算错会导致反电动势估计弱一个量级）。

## 4. 实测波形特征

- 观测角度冻结为固定负值时，先查反电动势估计 eα/eβ 是否退化为恒定常数——这是离散化
  病态的间接表现，不是观测器本身故障。

## 5. 对照结论

- 与吸尘器电机（`vacuum-motor.md`）对照：电感差异大（十几uH vs 231uH），但"强拖失步"
  根因相同（转子跟不上磁场），只是临界点不同。航模电机空载同步极限高，吸尘器电机带
  风机叶片同步极限低。验证了"按物理根源聚合"的有效性。
