## 4. 踩过的坑及解决方案

> 调试中按"现象 → SKILL.md 索引 → 排查卡"定位后，已验证的根因与解法归档到此处。

### 坑1：U/V 相 PWM 引脚修正后，相电流采样通道未跟着改（2026-09）
- **现象**：三相 PWM 引脚按原理图 U9 修正（U/V 对调）后，电机一跑即硬件过流锁死；
  iq 本应为正（电动状态）却读出负值
- **根因**：`foc_init.c` 相电流采样多通道配置（`ADC_MultiChannel1Config/2Config`
  → OP0/OP1）未跟随 PWM 相序引脚改动同步适配，iu/iv 采到错相电流，电流反馈与
  输出电压矢量错位→电流环正反馈→真实电流冲到硬件过流阈值；采样相序错同时使
  iq 符号整体反掉
- **解决**："PWM 引脚→相"与"采样通道→iu/iv"两条映射链逐相并排核对后同步修正。
  通用化描述与 AI 校对 IO 时的提醒要求见排查卡 `sampling-modulation.md` 坑3

## 6. 对照结论

- 与 25W 旧电机（`hv-fan-motor.md`）**同平台同驱动板**：霍尔链路、两步标定流程、
  保护框架、VOFA 观测通道全部可复用；
- 主要差异：功率等级（25W→62W）、转速域（旧机电压上限 ~4800rpm 级→本机铭牌 1550rpm 级），
  转速域常量已整体下移；
- 旧电机的标定产物**不可继承**：角度表/HALL_ANGLE_OFFSET（换霍尔安装）、
  IQ_SIN_K（换转子谐波）、环路增益（换 R/L/J/KT）。
