## 4. 踩过的坑及解决方案

> 调试中按"现象 → SKILL.md 索引 → 排查卡"定位后，已验证的根因与解法归档到此处。

### 坑1：U/V 相 PWM 引脚修正后，相电流采样通道未跟着改（2026-09）
- **现象**：三相 PWM 引脚按原理图 U9 修正（U/V 对调）后，电机一跑即硬件过流锁死；
  iq 本应为正（电动状态）却读出负值
- **根因**：`foc_init.c` 相电流采样多通道配置（`ADC_MultiChannel1Config/2Config`
  → OP0/OP1）未跟随 PWM 相序引脚改动同步适配，iu/iv 采到错相电流，电流反馈与
  输出电压矢量错位→电流环正反馈→真实电流冲到硬件过流阈值；采样相序错同时使
  iq 符号整体反掉
- **解决**："PWM 引脚→相"与"采样通道→iu/iv"两条映射链逐相并排核对后同步修正。
  通用化描述与 AI 校对 IO 时的提醒要求见排查卡 `sampling-modulation.md` 坑3

### 坑2：AC115V 带载转速被母线电压封顶 → 接入闭环弱磁（2026-10）
- **现象**：AC115V、目标 1550rpm，输出 47.58W 时转速只到 **1394rpm**；
  `svp.percent=60399` 顶满 `PERCENT_MAX=60400`，而 `iq_ref=1881` 未顶 `MAX_IQ=2096`；
  负载再加重则转速与效率同降；调速度环增益、加电流都无效
- **根因**：电压封顶，非转矩不足。115V 整流母线 ≈163V DC（估算），SVPWM 线性区相电压
  峰值 ≈0.577·Vdc ≈94V，与该 115V 绕组额定点反电势峰值 ≈115·√2/√3 ≈94V **同量级**
  → 电压裕量近零；负载电流的 `Rs·iq`、`ωLq·iq` 压降只能靠转速回落让出反电势项来换取。
  即排查卡 `field-weakening.md` 坑1 的典型形态
- **解决**：接入 **`flux_weak_ctrl()` 闭环弱磁**（见第 5 节），
  以 `svp.percent` 为被控量、`id_ref` 为输出，`id_ref` 不再来自 MTPA 曲线。
  实测有效：输出包络由 46.2W 扩到 **51.93W**；固定 −400 方案的"轻载白付效率税、
  重载才回本"问题由闭环按需给药取代
- **配套整定**（弱磁注入的 −id 是 d 轴电流环的真实给定，需相应放宽电流环/速度环）：
  `CURRENT_KI` 8192→36384、`SPEED_KP` 2500→10000、`SPEED_KI`→100、
  `SPEED_CONRTOL_FRE` 5→15ms、`SPEED_HIGH/LOW` 下调至 1500/760
- **未闭环项**：方形 iq 限幅未改电流圆；闭环弱磁后的负载-效率表待补（以确认轻载税
  已收回）；"到速后泄放"在重载窄带可能引入慢周期转速摆动（推导，未实测，见
  `field-weakening.md` 坑6 边界）

### 坑3：逆风刹车回正后 iq 钉死制动值、转速狂飙到超时重启（2026-10）
- **现象**：逆风 BRAKE 中转子刹停回正开始正转，`cuv.iq_ref` 仍钉在
  `BRAKE_I_BRAKE=400`，转速狂飙直到 `BRAKE_TIMEOUT_TICKS`（5s）/超速 abort
  重启；同时 `foc.speed` 不变号（BRAKE 态 sign 已被 wind_judge 切到风系 +
  PLL 符号跟 foc.dir 走），看速度永远判不出反转
- **根因**：停转判据只有 `hall_no_edge_time > BRAKE_NO_EDGE_TICKS`（300ms
  无沿）单一出口，反转后霍尔沿不断、计时被每沿清零，停转确认永不触发；
  过零后制动 iq 变驱动 iq 正反馈加速，叠加插补方向分支跟风系 foc.dir 的
  ±120° 锯齿失真。通用化见排查卡 `hall-sensor.md` 坑6/坑7
- **解决**：制动段加"已回正"出口，与无沿出口**或关系**：
  `wind_dir*cmd_sign > 0`（序列环判向 × 命令方向系符号，cmd_sign 取
  `input_cmd_dir()` 锁存值、不可用风系 foc.sign）且 `|hall_rpm| >
  BRAKE_REV_RPM(150)`（周期法幅值门限）→ `brake_to_wind_det()` 封波整套
  重装回 `WIND_DET` 复判（恢复命令坐标系、清判向去抖/无沿计时/PI 积分/iq），
  复判一般落顺风 TAIL / 静止 STILL 走 ORIENT 正常切入；重进次数
  `BRAKE_REENTRY_MAX(2)` 封顶、超限走 `brake_abort`（计一次 restart）防
  检测↔制动 ping-pong 掩盖真故障；原 300ms 无沿窗口保留作静止/贴零兜底。
  计数在成功进 RUN 时清零。实测修复生效
- **配套备注**：`PROT_EN_PHASE_LOSS` 台架期间临时置 0（与本问题无关，
  恢复判据验证后记得置回 1）

### 坑4：电流环 Ki 过小"不起作用"；幅值包络波动靠加大 Ki 稳住（2026-10）
- **现象（台架实测）**：① Ki 太小时改参数台架"没反应"，扰动后电流长时间贴不回给定；
  ② 转速/负载平稳时相电流整体正弦但幅值包络时高时低，加大电流环 Ki 后幅值稳定
- **根因**：积分器每拍只能挪 `err×Ki>>15` 码（本平台 `PIControl` Q15 定标，见
  `pid.c`/`current.h`），这个斜率决定"攒出反电势/死区抵消电压"的速度——Ki×err 太小
  即表现为"Ki 不起作用"（定点实现若先移位再累加，还会逐拍截断彻底冻结）。幅值包络
  波动本身是未被消除的准稳态误差：P 项只能缩小误差，只有积分器能攒出抵消扰动的
  电压（电流源刚度），Ki 小重建慢即幅值晃——"Ki 消稳态误差"与"Ki 稳幅值"同机制
- **判断（积分斜率法）**：`err_max×Ki>>15` = 每拍输出增量，建 ΔU 码电压的收敛拍数×Ts
  必须远小于扰动变化时间尺度（本机 Ki=36384、err=200 码 → ≈222 码/拍，建 2000 码
  <1ms；Ki 若 30 → ≈0.9s，即"没反应"）。幅值晃先分三种：锁死在转子角度→角度表/死区；
  跟着 iq_ref 晃→速度环；给定平稳自己慢晃→本坑
- **解决**：按斜率法加大 Ki（与坑2 弱磁配套整定 8192→36384 方向一致，机制此处闭环）；
  上限防振铃/对 ADC 噪声敏感，输出限幅+Kc 抗饱和防积分钉死。通用化见
  `current-loop.md` 坑2/坑3；调试序位原则（先相电流正弦、后外环整定）见
  `current-loop.md` 坑4

### 5.4 闭环弱磁实现要点（本机代码，供对照）

| 项 | 取值/做法 | 依据 |
|---|---|---|
| 被控量 | `svp.percent`（调制度，与 PERCENT_MAX 同标度，65536≈满占空比） | 饱和即顶在 PERCENT_MAX，可作"缺不缺电压"的指示 |
| 给定（调节点） | 60000 | **不可取 60400**：取等于饱和值则误差恒 0、弱磁永不介入（坑4）；留 400 码余量 |
| 反馈下限 | 59000 | 压小轻载深跌时的正误差（PI 内部只钳 +7000），防重入突跳 |
| 输出 | `id_ref`，PI 限幅 `[0, −500]`（≈0.38A） | 上限 0 = 不产生正 id；深度上限按退磁/电流预算定（坑5） |
| 出口兜底 | `[−1000, 0]` 再钳一道 | 防日后调宽限幅参数导致弱磁深度失控 |
| 抗饱和 | PI 内置 Kc 反算 | 输出饱和期间积分器被钉在限幅边界，电压一重新饱和立即建立 |
| 到速分支 | `speed < target` 时跟踪实时 percent；到速后冻结并主动往 0 泄放 | 回收轻载铜损（坑6）；负载再饱和、转速跌回目标以下时自动重进跟踪 |
| 节拍 | 速度环节拍（当前 `SPEED_CONRTOL_FRE`=**15ms**；代码注释里的"5ms"是该宏改 15 前的旧值） | 比电流环慢千倍、比速度环本身还慢，不与速度环抢方向盘 |
| 取代关系 | 原 MTPA 曲线函数成为死代码 | MTPA ≠ 弱磁：MTPA 求"每安培转矩最大"，弱磁求"电压不足时换转速"；表贴式电机 MTPA 本就是 id=0 |

## 7. 对照结论

- 与 25W 旧电机（`hv-fan-motor.md`）**同平台同驱动板**：霍尔链路、两步标定流程、
  保护框架、VOFA 观测通道全部可复用；
- 主要差异：功率等级（25W→62W）、转速域（旧机电压上限 ~4800rpm 级→本机铭牌 1550rpm 级），
  转速域常量已整体下移；
- 旧电机的标定产物**不可继承**：角度表/HALL_ANGLE_OFFSET（换霍尔安装）、
  IQ_SIN_K（换转子谐波）、环路增益（换 R/L/J/KT）。
