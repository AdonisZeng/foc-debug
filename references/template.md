# 模板：新增电机类型板块

> 复制本文件为新的板块文件（如 `references/high-inductance-motor.md`），
> 把标题中的"电机类型"改成专业名称，再按结构填写。
> 填写完成后，在 SKILL.md 的「板块索引」登记，并更新 description 的触发关键词。

## 板块规则（写死）

1. **只写已实测验证或严格物理推导确认的调试思路与方法。**
2. **不写具体芯片、文件路径、寄存器、固件数值**——换芯片要能继续用。
3. **不写"刚想到、还没验证"的想法**；若某条思路尚未上机，可先在板块末尾单独列出并
   明确标注"待验证"，待实测确认后再转为正式条目。
4. 每条坑给出四个要素：**现象 → 物理根源 → 判断方法 → 处理思路**。
